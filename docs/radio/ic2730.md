# IC-2730

The blocks of the category *IC-2730* control the ICOM IC-2730. They are grouped by topic:

| Group | Content |
|-------|---------|
| [Frequency & Mode](#frequency) | frequency, mode, VFO, split/duplex |
| [Receiver](#receiver) | volume, squelch, squelch status |
| [Transmit](#transmit) | transmitting, RF power, repeater tone |
| [Meters](#meters) | S-meter |
| [Settings](#settings) | functions |

Blocks that read a value use the **last answer** of the radio, see [Reading values from the radio](../blocks.md#reading-values).

!!! warning "Connect to the radio first"
    By default iCOMpadre talks to an IC-705 via Bluetooth. Put the block
    [Connect to IC-2730 via cable](../base/radio.md#connect_radio) into [OnStartup](../base/program.md#onstartup),
    and connect the REMOTE jack of the radio to iCOMpadre with a mono cable. The block uses the default CI-V address of the IC-2730 (90h);
    if you changed it in the menu of the radio, use [Connect to CI-V address](../base/radio.md#connect_address) instead.
    The baud rate of the block has to match the CI-V baud rate of the radio (or set the radio to *Auto*).

The CI-V commands and page numbers refer to the *IC-2730A/E EXMENU items and CI-V information*.
All blocks are created from the description of the radio in `studio/radio/ic2730.js`.

## <span style="color:#5fa8c9">■</span> Frequency & Mode {#frequency}

### Set Frequency {#ic2730_set_frequency}

![Set Frequency block](../img/ic2730_set_frequency.png){ width="208" }

Sets the frequency of the radio.

CI-V: `05 + 5 bytes BCD, least significant byte first` (p. 26)

??? info "Lua code"
    ```lua
    sendCommand({0x05}, frequencyToBcd(145.5 * 1e6, 5))
    ```

### Set Operating Mode {#ic2730_set_operating_mode}

![Set Operating Mode block](../img/ic2730_set_operating_mode.png){ width="216" }

Sets the operating mode of the radio.
Choices: *FM*, *FM-N*, *AM*, *AM-N*.

CI-V: `06 + mode` (p. 26)

??? info "Lua code"
    ```lua
    sendCommand({0x06}, {0x05, 0x01})
    ```

### Select VFO / Band {#ic2730_select_vfo}

![Select VFO / Band block](../img/ic2730_select_vfo.png){ width="141" }

Selects A band or B band.

CI-V: `07 + D0 (A band) / D1 (B band)` (p. 25)

??? info "Lua code"
    ```lua
    sendCommand({0x07, 0xD0})
    ```

### Split / Duplex {#ic2730_set_split}

![Split / Duplex block](../img/ic2730_set_split.png){ width="122" }

Selects Simplex, Duplex - or Duplex +.

CI-V: `0F + 10 (Simplex) / 11 (Duplex -) / 12 (Duplex +)` (p. 25)

??? info "Lua code"
    ```lua
    sendCommand({0x0F, 0x10})
    ```

### Operating frequency {#ic2730_get_operating_frequency}

![Operating frequency block](../img/ic2730_get_operating_frequency.png){ width="219" }

Reads the current frequency of the radio.

CI-V: `03` (p. 26)

??? info "Lua code"
    ```lua
    icomReadFrequency()
    ```

### Operating Mode {#ic2730_get_operating_mode}

![Operating Mode block](../img/ic2730_get_operating_mode.png){ width="134" }

Reads the current operating mode of the radio (FM, FM-N, AM or AM-N).

CI-V: `04` (p. 26)

??? info "Lua code"
    ```lua
    icomName(icomQuery({0x04}), {[1281] = "FM", [1282] = "FM-N", [513] = "AM", [514] = "AM-N"}, "Unknown")
    ```

## <span style="color:#5fa8c9">■</span> Receiver {#receiver}

### Set AF Level {#ic2730_set_af_level}

![Set AF Level block](../img/ic2730_set_af_level.png){ width="174" }

Sets the AF output level (volume) (in %).

CI-V: `14 01 + 0000 ~ 0255` (p. 25)

??? info "Lua code"
    ```lua
    sendCommand({0x14, 0x01}, icomPercent(50))

    ```

![Squelch Level block](../img/ic2730_get_squelch_level.png){ width="121" }

### Is Squelch open? {#ic2730_is_squelch_open}

![Is Squelch open? block](../img/ic2730_is_squelch_open.png){ width="142" }

CI-V: `15 01 -> 00 (closed) / 01 (open)` (p. 25)

## <span style="color:#5fa8c9">■</span> Transmit {#transmit}

### Transmit {#ic2730_set_transmit}

![Transmit block](../img/ic2730_set_transmit.png){ width="153" }

Switches the transmitter on (like pressing PTT) or back to receive. Make sure your program switches it off again!.

CI-V: `1C 00 + 00 (RX) / 01 (TX)` (p. 25)

??? info "Lua code"
    ```lua
    sendCommand({0x1C, 0x00}, {0x01})
    ```

### Set RF Power {#ic2730_set_rf_power}

![Set RF Power block](../img/ic2730_set_rf_power.png){ width="188" }

Sets the RF power: LOW, MID or HIGH.

CI-V: `14 0A + 0042 (LOW) / 0128 (MID) / 0213 (HIGH)` (p. 26)

??? info "Lua code"
    ```lua
    sendCommand({0x14, 0x0A}, numberToBcd(42, 2))
    ```

### RF Power {#ic2730_get_rf_power}

![RF Power block](../img/ic2730_get_rf_power.png){ width="94" }

Reads the RF power setting: LOW, MID or HIGH.

CI-V: `14 0A -> 0000 ~ 0084 (LOW), 0085 ~ 0170 (MID), 0171 ~ 0255 (HIGH)` (p. 26)

??? info "Lua code"
    ```lua
    (icomReadNumber({0x14, 0x0A}) <= 84 and "LOW" or (icomReadNumber({0x14, 0x0A}) <= 170 and "MID" or "HIGH"))
    ```

### Set Repeater Tone {#ic2730_set_tone_frequency}

![Set Repeater Tone block](../img/ic2730_set_tone_frequency.png){ width="218" }

Sets the frequency of the repeater tone (CTCSS), e.g. 88.5 Hz.

CI-V: `1B 00 + 3 bytes BCD in 0.1 Hz` (p. 26)

??? info "Lua code"
    ```lua
    sendCommand({0x1B, 0x00}, numberToBcd(math.floor(88.5 * 10 + 0.5), 3))
    ```

### Is Transmitting? {#ic2730_is_transmitting}

![Is Transmitting? block](../img/ic2730_is_transmitting.png){ width="132" }

True while the radio transmits.

CI-V: `1C 00 -> 00 (RX) / 01 (TX)` (p. 25)

??? info "Lua code"
    ```lua
    icomReadOn({0x1C, 0x00})
    ```

## <span style="color:#5fa8c9">■</span> Meters {#meters}

### S-Meter {#ic2730_get_s_meter}

![S-Meter block](../img/ic2730_get_s_meter.png){ width="168" }

Reads the S-meter in S-units (0 ~ 9).

CI-V: `15 02 -> 0000 = S0, 0170 = S9` (p. 25)

??? info "Lua code"
    ```lua
    math.min(9, icomMeter({0x15, 0x02}, {{0, 0}, {170, 9}}))
    ```

## <span style="color:#5fa8c9">■</span> Settings {#settings}

### Switch function {#ic2730_switch_function}

![Switch function block](../img/ic2730_switch_function.png){ width="240" }

Switches a function of the radio on or off.
Choices: *Repeater Tone*, *Tone Squelch*, *DTCS*, *VOX*.

CI-V: `16 xx + 00 (off) / 01 (on)` (p. 25)

??? info "Lua code"
    ```lua
    sendCommand({0x16, 0x42}, {0x01})
    ```

### Is function on? {#ic2730_is_function_on}

![Is function on? block](../img/ic2730_is_function_on.png){ width="198" }

*True* if the function of the radio is switched on.
Choices: *Repeater Tone*, *Tone Squelch*, *DTCS*, *VOX*.

CI-V: `16 xx -> 00 (off) / 01 (on)` (p. 25)

??? info "Lua code"
    ```lua
    icomReadByte({0x16, 0x42}) ~= 0
    ```
