# IC-9700

The blocks of the category *IC-9700* control the ICOM IC-9700. They are grouped by topic:

| Group | Content |
|-------|---------|
| [Frequency & Mode](#frequency) | frequency, mode, data mode, tuning step, VFO, split/duplex, memory, RIT, scan |
| [Receiver](#receiver) | volume, RF gain, squelch, preamp, attenuator, AGC, squelch status, DSP filter, notch width, digital squelch, tone squelch status |
| [Transmit](#transmit) | transmitting, RF power, mic gain, repeater tone, tone function, tone squelch, DTCS, CSQL, SSB bandwidth, compressor |
| [Meters](#meters) | S-meter, SWR, power, ALC, voltage, current, compression, overflow |
| [CW & Voice](#cwvoice) | CW messages, keyer speed, voice memories, speech, break-in, CW pitch |
| [GPS & Time](#gps) | position and time, clock, locator, GPS TX mode |
| [Settings](#settings) | functions, display, power on/off, more levels, menu settings |

Blocks that read a value use the **last answer** of the radio, see [Reading values from the radio](../blocks.md#reading-values).

!!! warning "Connect to the radio first"
    By default iCOMpadre talks to an IC-705 via Bluetooth. Put the block
    [Connect to IC-9700 via cable](../base/radio.md#connect_radio) into [OnStartup](../base/program.md#onstartup),
    and connect the REMOTE jack of the radio to iCOMpadre with a mono cable. The block uses the default CI-V address of the IC-9700 (A2h);
    if you changed it in the menu of the radio, use [Connect to CI-V address](../base/radio.md#connect_address) instead.
    The baud rate of the block has to match the CI-V baud rate of the radio (or set the radio to *Auto*).

The CI-V commands and page numbers refer to the *IC-9700 CI-V reference guide*.
All blocks are created from the description of the radio in `studio/radio/ic9700.js`.

## <span style="color:#5fa8c9">■</span> Frequency & Mode {#frequency}

### Set Frequency {#ic9700_set_frequency}

![Set Frequency block](../img/ic9700_set_frequency.png){ width="208" }

Sets the frequency of the radio.

CI-V: `05 + 5 bytes BCD, least significant byte first` (p. 13)

??? info "Lua code"
    ```lua
    sendCommand({0x05}, frequencyToBcd(145.8 * 1e6, 5))
    ```

### Set Operating Mode {#ic9700_set_operating_mode}

![Set Operating Mode block](../img/ic9700_set_operating_mode.png){ width="223" }

Sets the operating mode of the radio.
Choices: *LSB*, *USB*, *AM*, *CW*, *RTTY*, *FM*, *CW-R*, *RTTY-R*, *DV*, *DD*.

CI-V: `06 + mode` (p. 13)

??? info "Lua code"
    ```lua
    sendCommand({0x06}, {0x00})
    ```

### Data Mode {#ic9700_set_data_mode}

![Data Mode block](../img/ic9700_set_data_mode.png){ width="135" }

Switches the data mode (e.g. USB-D for digital modes like FT8) on or off.

CI-V: `1A 06 + 01 01 (on, FIL1) / 00 00 (off)` (p. 11)

??? info "Lua code"
    ```lua
    sendCommand({0x1A, 0x06}, {0x01, 0x01})
    ```

### Set Tuning Step {#ic9700_set_tuning_step}

![Set Tuning Step block](../img/ic9700_set_tuning_step.png){ width="292" }

Sets the tuning step of the radio.
Choices: *OFF (10Hz or 1Hz)*, *100Hz*, *500Hz*, *1kHz*, *5kHz*, *6.25kHz*, *10kHz*, *12.5kHz*, *20kHz*, *25kHz*, *50kHz*, *100kHz*.

CI-V: `10 + step` (p. 4)

??? info "Lua code"
    ```lua
    sendCommand({0x10, 0x00})
    ```

### Select VFO / Band {#ic9700_select_vfo}

![Select VFO / Band block](../img/ic9700_select_vfo.png){ width="131" }

Selects VFO A, VFO B, Main band or Sub band.

CI-V: `07 + 00 (VFO A) / 01 (VFO B) / D0 (Main band) / D1 (Sub band)` (p. 4)

??? info "Lua code"
    ```lua
    sendCommand({0x07, 0x00})
    ```

### Equalize VFO A and VFO B {#ic9700_equalize_vfo}

![Equalize VFO A and VFO B block](../img/ic9700_equalize_vfo.png){ width="200" }

Copies the frequency and mode of the selected one to the other one (VFO A and VFO B).

CI-V: `07 A0` (p. 4)

??? info "Lua code"
    ```lua
    sendCommand({0x07, 0xA0})
    ```

### Exchange VFO A and VFO B {#ic9700_exchange_vfo}

![Exchange VFO A and VFO B block](../img/ic9700_exchange_vfo.png){ width="214" }

Exchanges the frequency and mode of the main and sub band.

CI-V: `07 B0` (p. 4)

??? info "Lua code"
    ```lua
    sendCommand({0x07, 0xB0})
    ```

### Split / Duplex {#ic9700_set_split}

![Split / Duplex block](../img/ic9700_set_split.png){ width="119" }

Selects Split on, Split off, Simplex, Duplex - or Duplex +.

CI-V: `0F + 01 (Split on) / 00 (Split off) / 10 (Simplex) / 11 (Duplex -) / 12 (Duplex +)` (p. 4)

??? info "Lua code"
    ```lua
    sendCommand({0x0F, 0x01})
    ```

### Select Memory Channel {#ic9700_select_memory}

![Select Memory Channel block](../img/ic9700_select_memory.png){ width="208" }

Switches to the memory mode and selects the memory channel (1 ~ 99).

CI-V: `08 (memory mode), 08 + 0001 ~ 0099 (channel)` (p. 4)

??? info "Lua code"
    ```lua
    sendCommand({0x08})
    sendCommand({0x08}, numberToBcd(1, 2))
    ```

### RIT {#ic9700_set_rit}

![RIT block](../img/ic9700_set_rit.png){ width="87" }

Switches the RIT (receive incremental tuning) on or off.

CI-V: `21 01 + 00 / 01` (p. 11)

??? info "Lua code"
    ```lua
    sendCommand({0x21, 0x01}, {0x01})
    ```

### Set RIT offset {#ic9700_set_rit_offset}

![Set RIT offset block](../img/ic9700_set_rit_offset.png){ width="184" }

Sets the RIT offset (-9999 ~ +9999 Hz).

CI-V: `21 00 + 10Hz/1Hz, 1kHz/100Hz, direction` (p. 24)

??? info "Lua code"
    ```lua
    sendCommand({0x21, 0x00}, icomRitData(100))
    ```

### Scan {#ic9700_scan}

![Scan block](../img/ic9700_scan.png){ width="109" }

Starts a scan of the selected type, or stops it.
Choices: *stop*, *programmed/memory*, *programmed*, *ΔF*, *fine programmed*, *fine ΔF*, *memory*, *select memory*, *mode select*.

CI-V: `0E + 00 (stop) / scan type` (p. 4)

??? info "Lua code"
    ```lua
    sendCommand({0x0E, 0x00})
    ```

### Operating frequency {#ic9700_get_operating_frequency}

![Operating frequency block](../img/ic9700_get_operating_frequency.png){ width="219" }

Reads the current frequency of the radio.

CI-V: `03` (p. 13)

??? info "Lua code"
    ```lua
    icomReadFrequency()
    ```

### Operating Mode {#ic9700_get_operating_mode}

![Operating Mode block](../img/ic9700_get_operating_mode.png){ width="134" }

Reads the current operating mode of the radio (LSB, USB, AM, CW, RTTY, FM, CW-R, RTTY-R, DV or DD).

CI-V: `04` (p. 13)

??? info "Lua code"
    ```lua
    icomName(icomQuery({0x04}), {[0] = "LSB", [1] = "USB", [2] = "AM", [3] = "CW", [4] = "RTTY", [5] = "FM", [7] = "CW-R", [8] = "RTTY-R", [23] = "DV", [34] = "DD"}, "Unknown")
    ```

### Is Data Mode on? {#ic9700_is_data_mode}

![Is Data Mode on? block](../img/ic9700_is_data_mode.png){ width="144" }

*True* if the data mode (e.g. USB-D) is on.

CI-V: `1A 06 -> 00 (off) / 01 ~ 03 (on) + filter` (p. 11)

??? info "Lua code"
    ```lua
    icomReadByte({0x1A, 0x06}) ~= 0
    ```

### Is Split on? {#ic9700_is_split}

![Is Split on? block](../img/ic9700_is_split.png){ width="101" }

*True* if the split function is on.

CI-V: `0F -> 00 (split off) / 01 (split on)` (p. 4)

??? info "Lua code"
    ```lua
    icomReadByte({0x0F}) == 1
    ```

![S-Meter block](../img/ic9700_get_s_meter.png){ width="168" }

Reads the S-meter: in S-units (0 ~ 9), or in dB over S9 (negative below S9, 6 dB per S-unit).

CI-V: `15 02 -> 0000 = S0, 0120 = S9, 0241 = S9+60 dB` (p. 4)

??? info "Lua code"
    ```lua
    math.min(9, icomMeter({0x15, 0x02}, {{0, 0}, {120, 9}}))
    ```

### SWR {#ic9700_get_swr_meter_level}

![SWR block](../img/ic9700_get_swr_meter_level.png){ width="63" }

Reads the SWR while transmitting, e.g. 1.5.

CI-V: `15 12 -> 0000 = 1, 0048 = 1.5, 0080 = 2, 0120 = 3` (p. 5)

??? info "Lua code"
    ```lua
    icomMeter({0x15, 0x12}, {{0, 1}, {48, 1.5}, {80, 2}, {120, 3}})
    ```

### Power Output {#ic9700_get_power_output}

![Power Output block](../img/ic9700_get_power_output.png){ width="118" }

Reads the output power meter while transmitting (in % of the maximum).

CI-V: `15 11 -> 0000 = 0 %, 0143 = 50 %, 0213 = 100 %` (p. 4)

??? info "Lua code"
    ```lua
    icomMeter({0x15, 0x11}, {{0, 0}, {143, 50}, {213, 100}})
    ```

### ALC {#ic9700_get_alc}

![ALC block](../img/ic9700_get_alc.png){ width="57" }

Reads the ALC meter while transmitting (in %, 100 = end of the ALC zone).

CI-V: `15 13 -> 0000 = 0 %, 0120 = 100 %` (p. 5)

??? info "Lua code"
    ```lua
    icomMeter({0x15, 0x13}, {{0, 0}, {120, 100}})
    ```

### Supply Voltage {#ic9700_get_supply_voltage}

![Supply Voltage block](../img/ic9700_get_supply_voltage.png){ width="126" }

Reads the supply voltage of the final amplifier (in V).

CI-V: `15 15 -> 0000 = 0 V, 0013 = 10 V, 0241 = 16 V` (p. 5)

??? info "Lua code"
    ```lua

    ```

### Supply Current {#ic9700_get_supply_current}

CI-V: `15 16 -> 0000 = 0 A, 0121 = 10 A, 0241 = 20 A` (p. 5)

### Is Overflow? {#ic9700_is_overflow}

![Is Overflow? block](../img/ic9700_is_overflow.png){ width="110" }

*True* if the OVF indicator is on, i.e. the receiver is overloaded by a strong signal.

CI-V: `15 07 -> 00 (OVF off) / 01 (OVF on)` (p. 4)

??? info "Lua code"


### Compression {#ic9700_get_comp_meter}

![Compression block](../img/ic9700_get_comp_meter.png){ width="115" }

Reads the COMP meter while transmitting with the speech compressor (in dB).

??? info "Lua code"

## <span style="color:#5fa8c9">■</span> CW & Voice {#cwvoice}

### Send CW {#ic9700_send_cw}

![Send CW block](../img/ic9700_send_cw.png){ width="114" }

Sends the text (up to 30 characters) as CW. The radio has to be in CW mode with break-in on.

CI-V: `17 + ASCII codes` (p. 5)

??? info "Lua code"
    ```lua
    sendCommand({0x17}, icomTextBytes('CQ CQ'))
    ```

### Set CW Speed {#ic9700_set_keying_speed}

![Set CW Speed block](../img/ic9700_set_keying_speed.png){ width="210" }

Sets the keying speed of the electronic keyer (6 ~ 48 WPM).

CI-V: `14 0C + 0000 = 6 WPM ~ 0255 = 48 WPM` (p. 4)

??? info "Lua code"
    ```lua
    sendCommand({0x14, 0x0C}, icomWpm(20))
    ```

### Transmit Voice Memory {#ic9700_play_voice_memory}

![Transmit Voice Memory block](../img/ic9700_play_voice_memory.png){ width="218" }

Transmits a recorded voice memory (e.g. a CQ call), or stops it.

CI-V: `28 00 + 01 ~ 08 (T1 ~ T8) / 00 (stop)` (p. 12)

??? info "Lua code"
    ```lua
    sendCommand({0x28, 0x00}, {0x01})
    ```

### Announce {#ic9700_announce}

![Announce block](../img/ic9700_announce.png){ width="307" }

The radio speaks the selected information with its voice synthesizer.

CI-V: `13 00 / 01 / 02` (p. 4)

??? info "Lua code"
    ```lua
    sendCommand({0x13, 0x00})
    ```

### CW Speed {#ic9700_get_keying_speed}

![CW Speed block](../img/ic9700_get_keying_speed.png){ width="99" }

Reads the keying speed of the electronic keyer (in WPM).

CI-V: `14 0C -> 0000 = 6 WPM ~ 0255 = 48 WPM` (p. 4)

??? info "Lua code"
    ```lua
    math.floor(6 + icomReadNumber({0x14, 0x0C}) * 42 / 255 + 0.5)
    ```

### Set Break-In {#ic9700_set_break_in}

![Set Break-In block](../img/ic9700_set_break_in.png){ width="174" }

Sets the CW break-in function: off, semi or full break-in.
Choices: *OFF*, *semi*, *full*.

CI-V: `16 47 + 00 (OFF) / 01 (semi) / 02 (full)` (p. 5)

??? info "Lua code"
    ```lua
    sendCommand({0x16, 0x47}, {0x00})
    ```

### Break-In {#ic9700_get_break_in}

![Break-In block](../img/ic9700_get_break_in.png){ width="84" }

Reads the Break-In: OFF, semi or full.

CI-V: `16 47 -> 00 / 01 / 02` (p. 5)

??? info "Lua code"
    ```lua
    icomName(icomQuery({0x16, 0x47}), {[0] = "OFF", [1] = "semi", [2] = "full"}, "")
    ```

### Set CW Pitch {#ic9700_set_cw_pitch}

![Set CW Pitch block](../img/ic9700_set_cw_pitch.png){ width="182" }

Sets the CW pitch (300 ~ 900 Hz).

CI-V: `14 09 + 0000 = 300 ~ 0255 = 900 Hz` (p. 4)

## <span style="color:#5fa8c9">■</span> GPS & Time {#gps}

### Position {#ic9700_get_gps_position}

![Position block](../img/ic9700_get_gps_position.png){ width="155" }

Reads the position of the external GPS receiver, or the manually entered position. Latitude and longitude in degrees (north and east positive).
Choices: *latitude*, *longitude*, *altitude (m)*, *course (°)*, *speed (km/h)*.

CI-V: `23 00` (p. 24)

??? info "Lua code"
    ```lua
    icomGpsValue("lat")
    ```

### GPS Time {#ic9700_get_gps_time}

![GPS Time block](../img/ic9700_get_gps_time.png){ width="209" }

Reads the date and time (UTC) of the GPS. Unix time are the seconds since 1970-01-01.

CI-V: `23 00, date and time in UTC` (p. 24)

??? info "Lua code"
    ```lua
    icomGpsTime("text")
    ```

### Radio Clock {#ic9700_get_clock}

![Radio Clock block](../img/ic9700_get_clock.png){ width="210" }

Reads the date and time of the clock of the radio (local time).

CI-V: `1A 05 01 79 (date) and 1A 05 01 80 (time)` (p. 8)

??? info "Lua code"
    ```lua
    icomClock({0x1A, 0x05, 0x01, 0x79}, {0x1A, 0x05, 0x01, 0x80}, "time")
    ```

### Locator {#ic9700_locator}

![Locator block](../img/ic9700_locator.png){ width="276" }

Calculates the Maidenhead locator (6 characters, e.g. JN77rb) of a position.

??? info "Lua code"
    ```lua
    icomLocator(47.07, 15.44)
    ```

![Set GPS TX Mode block](../img/ic9700_set_gps_tx_mode.png){ width="213" }

Selects which position data is transmitted in DV mode.
Choices: *OFF*, *D-PRS*, *NMEA*.

CI-V: `16 5C + 00 (OFF) / 01 (D-PRS) / 02 (NMEA)` (p. 5)

??? info "Lua code"
    ```lua

    ```

### GPS TX Mode {#ic9700_get_gps_tx_mode}

![GPS TX Mode block](../img/ic9700_get_gps_tx_mode.png){ width="123" }

Reads the GPS TX Mode: OFF, D-PRS or NMEA.

## <span style="color:#5fa8c9">■</span> Settings {#settings}

### Switch function {#ic9700_switch_function}

![Switch function block](../img/ic9700_switch_function.png){ width="235" }

Switches a function of the radio on or off.
Choices: *Noise Blanker*, *Noise Reduction*, *Auto Notch*, *Manual Notch*, *Speech Compressor*, *Monitor*, *VOX*, *Repeater Tone*, *Tone Squelch*, *DTCS*, *Twin Peak Filter*, *AFC*, *Dualwatch*, *Satellite Mode*, *IP Plus*, *Dial Lock*.

CI-V: `16 xx + 00 (off) / 01 (on)` (p. 5)

??? info "Lua code"
    ```lua
    sendCommand({0x16, 0x22}, {0x01})
    ```

### Set LCD Brightness {#ic9700_set_lcd_brightness}

![Set LCD Brightness block](../img/ic9700_set_lcd_brightness.png){ width="220" }

Sets the LCD brightness (in %).

CI-V: `14 19 + 0000 ~ 0255` (p. 4)

??? info "Lua code"
    ```lua
    sendCommand({0x14, 0x19}, icomPercent(50))
    ```

### LCD Brightness {#ic9700_get_lcd_brightness}

![LCD Brightness block](../img/ic9700_get_lcd_brightness.png){ width="131" }

Reads the LCD brightness (in %).

CI-V: `14 19 -> 0000 ~ 0255` (p. 4)

??? info "Lua code"
    ```lua
    icomReadPercent({0x14, 0x19})
    ```

### Switch Radio {#ic9700_set_power}

![Switch Radio block](../img/ic9700_set_power.png){ width="149" }

Switches the radio off or on. Switching on only works if the radio is in standby.

CI-V: `18 00 (off) / 18 01 (on)` (p. 5)

??? info "Lua code"
    ```lua
    sendCommand({0x18, 0x00})
    ```

### Is function on? {#ic9700_is_function_on}

![Is function on? block](../img/ic9700_is_function_on.png){ width="193" }

*True* if the function of the radio is switched on.
Choices: *Noise Blanker*, *Noise Reduction*, *Auto Notch*, *Manual Notch*, *Speech Compressor*, *Monitor*, *VOX*, *Repeater Tone*, *Tone Squelch*, *DTCS*, *Twin Peak Filter*, *AFC*, *Dualwatch*, *Satellite Mode*, *IP Plus*, *Dial Lock*.

CI-V: `16 xx -> 00 (off) / 01 (on)` (p. 5)

??? info "Lua code"
    ```lua
    icomReadByte({0x16, 0x22}) ~= 0
    ```

### Set Level {#ic9700_set_level}

![Set Level block](../img/ic9700_set_level.png){ width="202" }

Sets a level in %. For a PBT or a notch position 50 % is the center.
Choices: *NR level*, *NB level*, *inner PBT (PBT1)*, *outer PBT (PBT2)*, *manual notch position*, *monitor level*, *VOX gain*, *anti-VOX gain*.

CI-V: `14 + 06 (NR level) / 12 (NB level) / 07 (inner PBT (PBT1)) / 08 (outer PBT (PBT2)) / 0D (manual notch position) / 15 (monitor level) / 16 (VOX gain) / 17 (anti-VOX gain) + 0000 ~ 0255` (p. 4)

??? info "Lua code"
    ```lua
    sendCommand({0x14, 0x06}, icomPercent(0))
    ```

### Level {#ic9700_get_level}

![Level block](../img/ic9700_get_level.png){ width="100" }

Reads a level (in %).
Choices: *NR level*, *NB level*, *inner PBT (PBT1)*, *outer PBT (PBT2)*, *manual notch position*, *monitor level*, *VOX gain*, *anti-VOX gain*.

CI-V: `14 xx -> 0000 ~ 0255` (p. 4)

??? info "Lua code"
    ```lua
    icomReadPercent({0x14, 0x06})
    ```

### Set Menu Setting {#ic9700_set_menu}

![Set Menu Setting block](../img/ic9700_set_menu.png){ width="319" }

Changes a setting of the menu (command 1A 05). The number of the setting and the format of its value (00 ~ 99 or 0000 ~ 9999) are in the CI-V reference guide of the radio.
Choices: *as 00 ~ 99*, *as 0000 ~ 9999*.

CI-V: `1A 05 + number of the setting (2 bytes BCD) + value (BCD)` (p. 5)

??? info "Lua code"
    ```lua
    sendCommand(icomMenuCmd(0), numberToBcd(0, 1))
    ```

### Menu Setting {#ic9700_get_menu}

![Menu Setting block](../img/ic9700_get_menu.png){ width="146" }

Reads a setting of the menu (command 1A 05) as number.

CI-V: `1A 05 + number of the setting (2 bytes BCD) -> value (BCD)` (p. 5)

??? info "Lua code"
    ```lua
    icomReadNumber(icomMenuCmd(0))
    ```
