# IC-705

The blocks of the category *IC-705* control the ICOM IC-705. They are grouped by topic:

| Group | Content |
|-------|---------|
| [Frequency & Mode](#frequency) | frequency, mode, VFO, split, memory, RIT, scan |
| [Receiver](#receiver) | volume, RF gain, squelch, preamp, attenuator, AGC, DSP filter, notch width, digital squelch |
| [Transmit](#transmit) | transmitting, RF power, mic gain, repeater tone, tone squelch, DTCS, compressor, SSB bandwidth |
| [Meters](#meters) | S-meter, SWR, power, voltage and current, compression, overflow |
| [CW & Voice](#cwvoice) | CW messages, keyer speed, break-in, CW pitch, voice memories, speech |
| [GPS & Time](#gps) | position and time of the internal GPS, GPS TX mode, clock, locator |
| [Settings](#settings) | functions like NB or NR, more levels, any setting of the menu, display, power |

!!! note "Reading values from the radio"
    Blocks that read a value ask the radio and use its **last answer**. Right after the start there is no answer yet:
    numbers are then 0, yes/no questions are *false* and texts are empty. Use them in [Periodically](../base.md#periodically), where they are asked again and again.

!!! tip "CI-V address"
    By default iCOMpadre talks to an IC-705 with its default CI-V address (A4h) via Bluetooth, no further block is needed.
    If you changed the CI-V address in the menu of the radio, put [Connect to CI-V address](../base.md#connect_address) into [OnStartup](../base.md#onstartup).

## <span style="color:#5fa8c9">■</span> Frequency & Mode {#frequency}

### Set Frequency {#ic705_set_frequency}

![Set Frequency block](../img/ic705_set_frequency.png){ width="215" }

Tunes the radio to a frequency. Choose the unit on the right: *Hz*, *kHz* or *MHz*.

Example: *Set Frequency to* 14.074 *MHz* tunes to the FT8 frequency on 20 m.

??? info "Lua code"
    ```lua
    sendCommand({0x05}, frequencyToBcd(14.074 * 1e6, 5))
    ```

### Set Operating Mode {#ic705_set_operating_mode}

![Set Operating Mode block](../img/ic705_set_operating_mode.png){ width="231" }

Changes the mode: LSB, USB, AM, CW, RTTY, FM, WFM, CW-R, RTTY-R or DV. The default filter of the mode is used.

??? info "Lua code"
    ```lua
    sendCommand({0x06}, {0x01})   -- USB
    ```

### Data Mode {#ic705_set_data_mode}

![Data Mode block](../img/ic705_set_data_mode.png){ width="143" }

Switches the data mode on or off. Together with USB this is *USB-D*, which is used for digital modes like FT8.

??? info "Lua code"
    ```lua
    sendCommand({0x1A, 0x06}, {0x01, 0x01})
    ```

### Set Tuning Step {#ic705_set_tuning_step}

![Set Tuning Step block](../img/ic705_set_tuning_step.png){ width="301" }

Sets how far the frequency changes with one click of the main dial.

??? info "Lua code"
    ```lua
    sendCommand({0x10, 0x03})   -- 1 kHz
    ```

### Select VFO A {#ic705_select_vfo_a}

![Select VFO A block](../img/ic705_select_vfo_a.png){ width="117" }

Switches to VFO A.

??? info "Lua code"
    ```lua
    sendCommand({0x07, 0x00})
    ```

### Select VFO B {#ic705_select_vfo_b}

![Select VFO B block](../img/ic705_select_vfo_b.png){ width="118" }

Switches to VFO B.

??? info "Lua code"
    ```lua
    sendCommand({0x07, 0x01})
    ```

### Equalize VFO A and VFO B {#ic705_equalize_vfo}

![Equalize VFO block](../img/ic705_equalize_vfo.png){ width="208" }

Copies frequency and mode of the selected VFO to the other one (A=B).

??? info "Lua code"
    ```lua
    sendCommand({0x07, 0xA0})
    ```

### Exchange VFO A and VFO B {#ic705_exchange_vfo}

![Exchange VFO block](../img/ic705_exchange_vfo.png){ width="217" }

Swaps frequency and mode of VFO A and VFO B (A/B).

??? info "Lua code"
    ```lua
    sendCommand({0x07, 0xB0})
    ```

### Split / Duplex {#ic705_set_split}

![Split block](../img/ic705_set_split.png){ width="126" }

* **Split on / off**: receive on one VFO and transmit on the other, e.g. for DX pile-ups.
* **Simplex / Duplex - / Duplex +**: transmit on the receive frequency, or shifted down or up, e.g. for repeaters.

??? info "Lua code"
    ```lua
    sendCommand({0x0F, 0x01})   -- split on
    ```

### Select Memory Channel {#ic705_select_memory}

![Select Memory Channel block](../img/ic705_select_memory.png){ width="216" }

Switches to the memory mode and selects a memory channel (0 to 99).

Example: connect two buttons to the pins and switch between your favourite repeaters.

??? info "Lua code"
    ```lua
    sendCommand({0x08})
    sendCommand({0x08}, numberToBcd(12, 2))
    ```

### RIT {#ic705_set_rit}

![RIT block](../img/ic705_set_rit.png){ width="95" }

Switches the RIT (receive incremental tuning) on or off. With RIT the receive frequency is shifted, the transmit frequency stays.

??? info "Lua code"
    ```lua
    sendCommand({0x21, 0x01}, {0x01})
    ```

### Set RIT offset {#ic705_set_rit_offset}

![Set RIT offset block](../img/ic705_set_rit_offset.png){ width="193" }

Sets how far the RIT shifts the receive frequency: -9999 to +9999 Hz.

??? info "Lua code"
    ```lua
    sendCommand({0x21, 0x00}, icomRitData(-150))
    ```

### Scan {#ic705_scan}

![Scan block](../img/ic705_scan.png){ width="116" }

Starts a scan of the selected type (programmed, memory, ΔF, ...), or stops it.

??? info "Lua code"
    ```lua
    sendCommand({0x0E, 0x22})   -- memory scan
    sendCommand({0x0E, 0x00})   -- stop
    ```

### Operating frequency {#ic705_get_operating_frequency}

![Operating frequency block](../img/ic705_get_operating_frequency.png){ width="226" }

The frequency the radio is tuned to, in Hz, kHz or MHz.

Example: *if operating frequency in MHz* < 10 *then set preamp to* OFF.

??? info "Lua code"
    ```lua
    icomReadFrequency() / 1e6
    ```

### Operating Mode {#ic705_get_operating_mode}

![Operating Mode block](../img/ic705_get_operating_mode.png){ width="142" }

The current mode as text: LSB, USB, AM, CW, RTTY, FM, WFM, CW-R, RTTY-R or DV.

??? info "Lua code"
    ```lua
    icomName(icomQuery({0x04}), {[0] = "LSB", [1] = "USB", [2] = "AM", [3] = "CW", [4] = "RTTY", [5] = "FM", [6] = "WFM", [7] = "CW-R", [8] = "RTTY-R", [23] = "DV"}, "Unknown")
    ```

### Is Data Mode on? {#ic705_is_data_mode}

![Is Data Mode on block](../img/ic705_is_data_mode.png){ width="153" }

*True* if the data mode (e.g. USB-D) is on.

??? info "Lua code"
    ```lua
    icomReadByte({0x1A, 0x06}) ~= 0
    ```

### Is Split on? {#ic705_is_split}

![Is Split on block](../img/ic705_is_split.png){ width="110" }

*True* if the split function is on.

??? info "Lua code"
    ```lua
    icomReadByte({0x0F}) == 1
    ```

## <span style="color:#5fa8c9">■</span> Transmit {#transmit}

!!! warning "Transmitting"
    Only transmit on frequencies and with power levels you are allowed to use, and make sure your program also switches the transmitter off again.

### Transmit {#ic705_set_transmit}

![Transmit block](../img/ic705_set_transmit.png){ width="161" }

Switches the transmitter on, like pressing the PTT, or back to receive.

Example: a foot switch at a pin: *if State of PIN C then Transmit on (TX) else Transmit off (RX)*.

??? info "Lua code"
    ```lua
    sendCommand({0x1C, 0x00}, {0x01})   -- TX
    sendCommand({0x1C, 0x00}, {0x00})   -- RX
    ```

### Set RF Power {#ic705_set_rf_power}

![Set RF Power block](../img/ic705_set_rf_power.png){ width="190" }

Sets the output power of the current band, in % of the maximum.

Example: never more than 50 % on 2 m: *if operating frequency in MHz > 144 and RF Power > 50 then set RF Power to 50*.

??? info "Lua code"
    ```lua
    sendCommand({0x14, 0x0A}, icomPercent(50))
    ```

### Set Mic Gain {#ic705_set_mic_gain}

![Set Mic Gain block](../img/ic705_set_mic_gain.png){ width="183" }

Sets the microphone gain, from 0 to 100 %.

??? info "Lua code"
    ```lua
    sendCommand({0x14, 0x0B}, icomPercent(50))
    ```

### Set Repeater Tone {#ic705_set_tone_frequency}

![Set Repeater Tone block](../img/ic705_set_tone_frequency.png){ width="226" }

Sets the frequency of the repeater tone (CTCSS), e.g. 88.5 Hz. Switch the tone on with [Switch Repeater Tone on](#ic705_switch_function).

??? info "Lua code"
    ```lua
    sendCommand({0x1B, 0x00}, numberToBcd(math.floor(88.5 * 10 + 0.5), 3))
    ```

### Is Transmitting? {#ic705_is_transmitting}

![Is Transmitting block](../img/ic705_is_transmitting.png){ width="140" }

*True* while the radio transmits.

Example: an *On Air* lamp, or switching a power amplifier with a relay at a pin.

??? info "Lua code"
    ```lua
    icomReadOn({0x1C, 0x00})
    ```

### RF Power {#ic705_get_rf_power}

![RF Power block](../img/ic705_get_rf_power.png){ width="102" }

The power setting of the current band, in % of the maximum.

??? info "Lua code"
    ```lua
    icomReadPercent({0x14, 0x0A})
    ```

### Mic Gain {#ic705_get_mic_gain}

![Mic Gain block](../img/ic705_get_mic_gain.png){ width="95" }

The current microphone gain, from 0 to 100 %.

??? info "Lua code"
    ```lua
    icomReadPercent({0x14, 0x0B})
    ```

### Set Tone Function {#ic705_set_tone_function}

![Set Tone Function block](../img/ic705_set_tone_function.png){ width="211" }

Selects what is sent and expected in FM mode: *OFF*, *TONE* (repeater tone), *TSQL* (tone squelch), *DTCS*, or a combination of a transmit (T) and a receive (R) function.

??? info "Lua code"

### Set Tone Squelch {#ic705_set_tsql_frequency}

![Set Tone Squelch block](../img/ic705_set_tsql_frequency.png){ width="210" }

Sets the frequency of the tone squelch (CTCSS) in Hz, e.g. 88.5. The repeater tone is set with [Set Repeater Tone](#ic705_set_tone_frequency).

## <span style="color:#5fa8c9">■</span> Meters {#meters}

### S-Meter {#ic705_get_s_meter}

![S-Meter block](../img/ic705_get_s_meter.png){ width="177" }

The signal strength, either

* in **S-units** from 0 to 9 (stronger signals are 9), or
* in **dB over S9**: 0 is S9, +20 is S9+20 dB, below S9 it is negative (6 dB per S-unit).

??? info "Lua code"
    ```lua
    math.min(9, icomMeter({0x15, 0x02}, {{0, 0}, {120, 9}}))
    ```

### SWR {#ic705_get_swr_meter_level}

![SWR block](../img/ic705_get_swr_meter_level.png){ width="71" }

The standing wave ratio while transmitting, e.g. 1.5. Values up to 3.0 are measured exactly.

Example: protect your radio: *if Is Transmitting? and SWR > 2.5 then Transmit off (RX)*.

??? info "Lua code"
    ```lua
    icomMeter({0x15, 0x12}, {{0, 1.0}, {48, 1.5}, {80, 2.0}, {120, 3.0}})
    ```

### Power Output {#ic705_get_power_output}

![Power Output block](../img/ic705_get_power_output.png){ width="127" }

The measured output power while transmitting, in % of the maximum.

??? info "Lua code"
    ```lua
    icomMeter({0x15, 0x11}, {{0, 0}, {143, 50}, {213, 100}})
    ```

### ALC {#ic705_get_alc}

![ALC block](../img/ic705_get_alc.png){ width="66" }

The ALC meter while transmitting, in %. Above 100 the signal is driven too hard: reduce the mic gain or the audio level of your digital mode program.

??? info "Lua code"
    ```lua
    icomMeter({0x15, 0x13}, {{0, 0}, {120, 100}})
    ```

### Supply Voltage {#ic705_get_supply_voltage}

![Supply Voltage block](../img/ic705_get_supply_voltage.png){ width="135" }

The supply voltage of the radio, in V.

Example: a guard for an external 12 V battery in portable operation: *if Supply Voltage < 11.5 then set RF Power to 10*.

??? info "Lua code"
    ```lua
    icomMeter({0x15, 0x15}, {{0, 0}, {75, 5}, {241, 16}})
    ```

### Supply Current {#ic705_get_supply_current}

![Supply Current block](../img/ic705_get_supply_current.png){ width="135" }

The current the radio draws, in A.

??? info "Lua code"
    ```lua
    icomMeter({0x15, 0x16}, {{0, 0}, {121, 2}, {241, 4}})
    ```

### Is on Battery? {#ic705_is_on_battery}

![Is on Battery block](../img/ic705_is_on_battery.png){ width="127" }

*True* if the radio runs on its battery pack, *false* with an external power supply.

??? info "Lua code"
    ```lua
    icomReadOn({0x1A, 0x0B})
    ```

### Compression {#ic705_get_comp_meter}

![Compression block](../img/ic705_get_comp_meter.png){ width="115" }

The COMP meter while transmitting with the speech compressor, in dB (0 ~ 25.5).

??? info "Lua code"
    ```lua
    icomMeter({0x15, 0x14}, {{0, 0}, {130, 15}, {210, 25.5}})
    ```

### Is Overflow? {#ic705_is_overflow}

![Is Overflow? block](../img/ic705_is_overflow.png){ width="110" }

*True* if the OVF indicator is on: a strong signal overloads the receiver. Switch on the attenuator or turn down the RF gain.

??? info "Lua code"
    ```lua
    icomReadOn({0x15, 0x07})
    ```

## <span style="color:#5fa8c9">■</span> CW & Voice {#cwvoice}

### Send CW {#ic705_send_cw}

![Send CW block](../img/ic705_send_cw.png){ width="122" }

Sends a text (up to 30 characters) in CW. The radio has to be in CW mode, with break-in on.

Example: an automatic CW identification every 10 minutes: *Send CW* "DE OE6GUE".

??? info "Lua code"
    ```lua
    sendCommand({0x17}, icomTextBytes('CQ DE OE6GUE'))
    ```

### Transmit Voice Memory {#ic705_play_voice_memory}

## <span style="color:#5fa8c9">■</span> GPS & Time {#gps}

The IC-705 has a GPS receiver and a clock. So your program knows where and when it is, without internet.

### GPS position {#ic705_get_gps_position}

![GPS position block](../img/ic705_get_gps_position.png){ width="142" }

The position of the GPS: *latitude* and *longitude* in degrees (north and east are positive), *altitude* in m, *course* in degrees and *speed* in km/h.
The GPS needs a fix, which may take a few minutes outdoors.

??? info "Lua code"
    ```lua
    icomGpsValue("lat")
    ```

### GPS Time {#ic705_get_gps_time}

![GPS Time block](../img/ic705_get_gps_time.png){ width="217" }

Date and time from the GPS, in UTC:

* **as text**: e.g. *2025-10-31 12:34:56*
* **unix time**: the seconds since 1970-01-01, e.g. for satellite calculations
* **year**, **month**, **day**, **hour**, **minute** or **second** as number

??? info "Lua code"
    ```lua
    icomGpsTime("unix")
    ```

### Radio Clock {#ic705_get_clock}

![Radio Clock block](../img/ic705_get_clock.png){ width="217" }

Date and time of the clock of the radio, in local time. It also works without a GPS fix.

Example: switch the radio off at night: *if Radio Clock hour = 23 then Switch Radio off*.

??? info "Lua code"
    ```lua
    icomClock({0x1A, 0x05, 0x01, 0x65}, {0x1A, 0x05, 0x01, 0x66}, "time")
    ```

### Locator {#ic705_locator}

![Locator block](../img/ic705_locator.png){ width="284" }

Calculates the Maidenhead locator (6 characters) of a position, e.g. *JN77rb* for Graz. Plug the [GPS position](#ic705_get_gps_position) into it to get your own locator.

??? info "Lua code"
    ```lua
    icomLocator(icomGpsValue("lat"), icomGpsValue("lon"))
    ```

### Set GPS TX Mode {#ic705_set_gps_tx_mode}

![Set GPS TX Mode block](../img/ic705_set_gps_tx_mode.png){ width="213" }

Selects which position data is sent in DV mode: *OFF*, *D-PRS* or *NMEA*.

??? info "Lua code"
    ```lua
    sendCommand({0x16, 0x5C}, {0x01})
    ```

### GPS TX Mode {#ic705_get_gps_tx_mode}

![GPS TX Mode block](../img/ic705_get_gps_tx_mode.png){ width="123" }

The GPS TX mode: *OFF*, *D-PRS* or *NMEA*.

??? info "Lua code"
    ```lua
    icomName(icomQuery({0x16, 0x5C}), {[0] = "OFF", [1] = "D-PRS", [2] = "NMEA"}, "")
    ```

## <span style="color:#5fa8c9">■</span> Settings {#settings}

### Switch function {#ic705_switch_function}

![Switch function block](../img/ic705_switch_function.png){ width="242" }

Switches a function of the radio on or off:
*Noise Blanker*, *Noise Reduction*, *Auto Notch*, *Manual Notch*, *Speech Compressor*, *Monitor*, *VOX*, *Repeater Tone*, *Tone Squelch*, *DTCS*, *Twin Peak Filter* or *Dial Lock*.

??? info "Lua code"
    ```lua
    sendCommand({0x16, 0x22}, {0x01})   -- noise blanker on
    ```

### Set LCD Brightness {#ic705_set_lcd_brightness}

![Set LCD Brightness block](../img/ic705_set_lcd_brightness.png){ width="228" }

Sets the brightness of the display backlight, from 0 to 100 %.

??? info "Lua code"
    ```lua
    sendCommand({0x14, 0x19}, icomPercent(100))
    ```

### Switch Radio {#ic705_set_power}

![Switch Radio block](../img/ic705_set_power.png){ width="157" }

Switches the radio off or on. Switching on only works if the radio is in standby: set *Power OFF Setting (for Remote Control)* to *Standby/Shutdown* in the menu of the radio.

??? info "Lua code"
    ```lua
    sendCommand({0x18, 0x00})   -- off
    ```

### Is function on? {#ic705_is_function_on}

![Is function on block](../img/ic705_is_function_on.png){ width="200" }

*True* if the selected function of the radio is on.

??? info "Lua code"
    ```lua
    icomReadByte({0x16, 0x40}) ~= 0   -- noise reduction
    ```

### LCD Brightness {#ic705_get_lcd_brightness}

![LCD Brightness block](../img/ic705_get_lcd_brightness.png){ width="140" }

The current brightness of the display backlight, from 0 to 100 %.

??? info "Lua code"
    ```lua
    icomReadPercent({0x14, 0x19})
    ```

### Set Level {#ic705_set_level}

![Set Level block](../img/ic705_set_level.png){ width="202" }

Sets one of the less used levels in %: NR level, NB level, inner and outer PBT, manual notch position, monitor level, VOX gain and anti-VOX gain. For the PBT and the notch position 50 % is the center.

??? info "Lua code"
    ```lua
    sendCommand({0x14, 0x06}, icomPercent(50))
    ```

### Set Menu Setting {#ic705_set_menu}

![Set Menu Setting block](../img/ic705_set_menu.png){ width="319" }

Changes any setting of the menu of the radio. The CI-V reference guide (command 1A 05, pages 5 to 13) lists the number of every setting and its values, e.g. 29 for the beep level (0000 ~ 0255) or 34 for the auto power off (00 ~ 04). Choose the format of the value as it is listed there: *00 ~ 99* (1 byte) or *0000 ~ 9999* (2 bytes).

??? info "Lua code"
    ```lua
    sendCommand(icomMenuCmd(29), numberToBcd(128, 2))
    ```

### Level {#ic705_get_level}

![Level block](../img/ic705_get_level.png){ width="100" }

Reads one of the levels of [Set Level](#ic705_set_level), in %.

??? info "Lua code"
    ```lua
    icomReadPercent({0x14, 0x06})
    ```

### Menu Setting {#ic705_get_menu}

![Menu Setting block](../img/ic705_get_menu.png){ width="146" }

Reads a setting of the menu as number, e.g. 29 for the beep level.

??? info "Lua code"
    ```lua
    icomReadNumber(icomMenuCmd(29))
    ```
