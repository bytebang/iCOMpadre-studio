# IC-718

The blocks of the category *IC-718* control the ICOM IC-718. They are grouped by topic:

| Group | Content |
|-------|---------|
| [Frequency & Mode](#frequency) | frequency, mode, VFO, split/duplex, memory, scan |
| [Receiver](#receiver) | volume, RF gain, squelch, preamp, attenuator, squelch status |
| [Transmit](#transmit) | RF power, mic gain |
| [Meters](#meters) | S-meter |
| [CW & Voice](#cwvoice) | keyer speed |
| [Settings](#settings) | functions |

!!! note "Reading values from the radio"
    Blocks that read a value ask the radio and use its **last answer**. Right after the start there is no answer yet:
    numbers are then 0, yes/no questions are *false* and texts are empty. Use them in [Periodically](../base.md#periodically), where they are asked again and again.

!!! warning "CI-V address and baud rate"
    iCOMpadre talks to the radio with the CI-V address of the IC-705 (A4h) at 19200 baud. In the CI-V settings of the IC-718,
    set the **CI-V address to A4h** (the default is 5Eh) and the **CI-V baud rate to 19200** (or Auto).

!!! info "Not tested yet"
    The manual lists the CI-V commands of the IC-718 without their data. The blocks use the values of the other Icom radios (e.g. the 20 dB attenuator, the S-meter scale), they have not been tested with an IC-718 yet.

The CI-V commands and page numbers refer to the *IC-718 instruction manual, chapter 13*.
All blocks are created from the description of the radio in `studio/radio/ic718.js`.

## <span style="color:#5fa8c9">■</span> Frequency & Mode {#frequency}

### Set Frequency {#ic718_set_frequency}

![Set Frequency block](../img/ic718_set_frequency.png){ width="208" }

Sets the frequency of the radio.

CI-V: `05 + 5 bytes BCD, least significant byte first` (p. 58)

??? info "Lua code"
    ```lua
    sendCommand({0x05}, frequencyToBcd(14.074 * 1e6, 5))
    ```

### Set Operating Mode {#ic718_set_operating_mode}

![Set Operating Mode block](../img/ic718_set_operating_mode.png){ width="223" }

Sets the operating mode of the radio.
Choices: *LSB*, *USB*, *AM*, *CW*, *RTTY*, *CW-R*, *RTTY-R*.

CI-V: `06 + mode` (p. 58)

??? info "Lua code"
    ```lua
    sendCommand({0x06}, {0x00})
    ```

### Select VFO / Band {#ic718_select_vfo}

![Select VFO / Band block](../img/ic718_select_vfo.png){ width="139" }

Selects VFO A or VFO B.

CI-V: `07 + 00 (VFO A) / 01 (VFO B)` (p. 58)

??? info "Lua code"
    ```lua
    sendCommand({0x07, 0x00})
    ```

### Equalize VFO A and VFO B {#ic718_equalize_vfo}

![Equalize VFO A and VFO B block](../img/ic718_equalize_vfo.png){ width="200" }

Copies the frequency and mode of the selected one to the other one (VFO A and VFO B).

CI-V: `07 A0` (p. 58)

??? info "Lua code"
    ```lua
    sendCommand({0x07, 0xA0})
    ```

### Exchange VFO A and VFO B {#ic718_exchange_vfo}

![Exchange VFO A and VFO B block](../img/ic718_exchange_vfo.png){ width="209" }

Exchanges the frequency and mode of the VFO A and VFO B.

CI-V: `07 B0` (p. 58)

??? info "Lua code"
    ```lua
    sendCommand({0x07, 0xB0})
    ```

### Split / Duplex {#ic718_set_split}

![Split / Duplex block](../img/ic718_set_split.png){ width="125" }

Selects Split on or Split off.

CI-V: `0F + 01 (Split on) / 00 (Split off)` (p. 58)

??? info "Lua code"
    ```lua
    sendCommand({0x0F, 0x01})
    ```

### Select Memory Channel {#ic718_select_memory}

![Select Memory Channel block](../img/ic718_select_memory.png){ width="208" }

Switches to the memory mode and selects the memory channel (1 ~ 99).

CI-V: `08 (memory mode), 08 + 0001 ~ 0099 (channel)` (p. 58)

??? info "Lua code"
    ```lua
    sendCommand({0x08})
    sendCommand({0x08}, numberToBcd(1, 2))
    ```

### Scan {#ic718_scan}

![Scan block](../img/ic718_scan.png){ width="109" }

Starts a scan of the selected type, or stops it.
Choices: *stop*, *programmed/memory*.

CI-V: `0E + 00 (stop) / scan type` (p. 58)

??? info "Lua code"
    ```lua
    sendCommand({0x0E, 0x00})
    ```

### Operating frequency {#ic718_get_operating_frequency}

![Operating frequency block](../img/ic718_get_operating_frequency.png){ width="219" }

Reads the current frequency of the radio.

CI-V: `03` (p. 58)

??? info "Lua code"
    ```lua
    icomReadFrequency()
    ```

### Operating Mode {#ic718_get_operating_mode}

![Operating Mode block](../img/ic718_get_operating_mode.png){ width="134" }

Reads the current operating mode of the radio (LSB, USB, AM, CW, RTTY, CW-R or RTTY-R).

CI-V: `04` (p. 58)

??? info "Lua code"
    ```lua
    icomName(icomQuery({0x04}), {[0] = "LSB", [1] = "USB", [2] = "AM", [3] = "CW", [4] = "RTTY", [7] = "CW-R", [8] = "RTTY-R"}, "Unknown")
    ```

### Is Split on? {#ic718_is_split}

![Is Split on? block](../img/ic718_is_split.png){ width="101" }

*True* if the split function is on.

CI-V: `0F -> 00 (split off) / 01 (split on)` (p. 58)

??? info "Lua code"
    ```lua
    icomReadByte({0x0F}) == 1
    ```

## <span style="color:#5fa8c9">■</span> Meters {#meters}

### S-Meter {#ic718_get_s_meter}

![S-Meter block](../img/ic718_get_s_meter.png){ width="168" }

Reads the S-meter: in S-units (0 ~ 9), or in dB over S9 (negative below S9, 6 dB per S-unit).

CI-V: `15 02 -> 0000 = S0, 0120 = S9, 0241 = S9+60 dB` (p. 58)

??? info "Lua code"
    ```lua
    math.min(9, icomMeter({0x15, 0x02}, {{0, 0}, {120, 9}}))
    ```

## <span style="color:#5fa8c9">■</span> CW & Voice {#cwvoice}

### Set CW Speed {#ic718_set_keying_speed}

![Set CW Speed block](../img/ic718_set_keying_speed.png){ width="210" }

Sets the keying speed of the electronic keyer (6 ~ 48 WPM).

CI-V: `14 0C + 0000 = 6 WPM ~ 0255 = 48 WPM` (p. 58)

??? info "Lua code"
    ```lua
    sendCommand({0x14, 0x0C}, icomWpm(20))
    ```

### CW Speed {#ic718_get_keying_speed}

![CW Speed block](../img/ic718_get_keying_speed.png){ width="99" }

Reads the keying speed of the electronic keyer (in WPM).

CI-V: `14 0C -> 0000 = 6 WPM ~ 0255 = 48 WPM` (p. 58)

??? info "Lua code"
    ```lua
    math.floor(6 + icomReadNumber({0x14, 0x0C}) * 42 / 255 + 0.5)
    ```

## <span style="color:#5fa8c9">■</span> Settings {#settings}

### Switch function {#ic718_switch_function}

![Switch function block](../img/ic718_switch_function.png){ width="235" }

Switches a function of the radio on or off.
Choices: *Noise Blanker*, *Noise Reduction*, *Auto Notch*, *Speech Compressor*, *VOX*.

CI-V: `16 xx + 00 (off) / 01 (on)` (p. 58)

??? info "Lua code"
    ```lua
    sendCommand({0x16, 0x22}, {0x01})
    ```

### Is function on? {#ic718_is_function_on}

![Is function on? block](../img/ic718_is_function_on.png){ width="193" }

*True* if the function of the radio is switched on.
Choices: *Noise Blanker*, *Noise Reduction*, *Auto Notch*, *Speech Compressor*, *VOX*.

CI-V: `16 xx -> 00 (off) / 01 (on)` (p. 58)

??? info "Lua code"
    ```lua
    icomReadByte({0x16, 0x22}) ~= 0
    ```
