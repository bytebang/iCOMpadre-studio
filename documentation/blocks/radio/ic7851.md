# IC-7851

The blocks of the category *IC-7851* control the ICOM IC-7851. They are grouped by topic:

| Group | Content |
|-------|---------|
| [Frequency & Mode](#frequency) | frequency, mode, data mode, tuning step, VFO, dualwatch, split/duplex, memory, RIT, scan |
| [Receiver](#receiver) | volume, RF gain, squelch, preamp, attenuator, AGC, squelch status |
| [Transmit](#transmit) | transmitting, RF power, mic gain, repeater tone |
| [Meters](#meters) | S-meter, SWR, power, ALC, voltage, current |
| [CW & Voice](#cwvoice) | CW messages, keyer speed, voice memories, speech |
| [GPS & Time](#gps) | clock |
| [Settings](#settings) | functions, display, power on/off |

!!! note "Reading values from the radio"
    Blocks that read a value ask the radio and use its **last answer**. Right after the start there is no answer yet:
    numbers are then 0, yes/no questions are *false* and texts are empty. Use them in [Periodically](../base.md#periodically), where they are asked again and again.

!!! warning "Connect to the radio first"
    By default iCOMpadre talks to an IC-705 via Bluetooth. Put the block
    [Connect to IC-7851 via cable](../base.md#connect_radio) into [OnStartup](../base.md#onstartup),
    and connect the REMOTE jack of the radio to iCOMpadre with a mono cable. The block uses the default CI-V address of the IC-7851 (8Eh);
    if you changed it in the menu of the radio, use [Connect to CI-V address](../base.md#connect_address) instead.
    The baud rate of the block has to match the CI-V baud rate of the radio (or set the radio to *Auto*).

The CI-V commands and page numbers refer to the *IC-7850/IC-7851 instruction manual, chapter 18*.
All blocks are created from the description of the radio in `studio/radio/ic7851.js`.

## <span style="color:#5fa8c9">■</span> Frequency & Mode {#frequency}

### Set Frequency {#ic7851_set_frequency}

![Set Frequency block](../img/ic7851_set_frequency.png){ width="208" }

Sets the frequency of the radio.

CI-V: `05 + 5 bytes BCD, least significant byte first` (p. 18-11)

??? info "Lua code"
    ```lua
    sendCommand({0x05}, frequencyToBcd(14.074 * 1e6, 5))
    ```

### Set Operating Mode {#ic7851_set_operating_mode}

![Set Operating Mode block](../img/ic7851_set_operating_mode.png){ width="223" }

Sets the operating mode of the radio.
Choices: *LSB*, *USB*, *AM*, *CW*, *RTTY*, *FM*, *CW-R*, *RTTY-R*, *PSK*, *PSK-R*.

CI-V: `06 + mode` (p. 18-11)

??? info "Lua code"
    ```lua
    sendCommand({0x06}, {0x00})
    ```

### Data Mode {#ic7851_set_data_mode}

![Data Mode block](../img/ic7851_set_data_mode.png){ width="135" }

Switches the data mode (e.g. USB-D for digital modes like FT8) on or off.

CI-V: `1A 06 + 01 01 (on, FIL1) / 00 00 (off)` (p. 18-9)

??? info "Lua code"
    ```lua
    sendCommand({0x1A, 0x06}, {0x01, 0x01})
    ```

### Set Tuning Step {#ic7851_set_tuning_step}

![Set Tuning Step block](../img/ic7851_set_tuning_step.png){ width="292" }

Sets the tuning step of the radio.
Choices: *OFF (10Hz or 1Hz)*, *100Hz*, *1kHz*, *5kHz*, *9kHz*, *10kHz*, *12.5kHz*, *20kHz*, *25kHz*.

CI-V: `10 + step` (p. 18-3)

??? info "Lua code"
    ```lua
    sendCommand({0x10, 0x00})
    ```

### Select VFO / Band {#ic7851_select_vfo}

![Select VFO / Band block](../img/ic7851_select_vfo.png){ width="163" }

Selects Main band or Sub band.

CI-V: `07 + D0 (Main band) / D1 (Sub band)` (p. 18-3)

??? info "Lua code"

Choices: *Noise Blanker*, *Noise Reduction*, *Auto Notch*, *Manual Notch*, *Speech Compressor*, *Monitor*, *VOX*, *Repeater Tone*, *Tone Squelch*, *VSC*, *DIGI-SEL*, *Twin Peak Filter*, *Dial Lock*.

CI-V: `16 xx -> 00 (off) / 01 (on)` (p. 18-4)

??? info "Lua code"
    ```lua
    icomReadByte({0x16, 0x22}) ~= 0
    ```
