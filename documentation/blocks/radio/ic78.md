# IC-78

The blocks of the category *IC-78* control the ICOM IC-78. They are grouped by topic:

| Group | Content |
|-------|---------|
| [Frequency & Mode](#frequency) | frequency, mode, memory, scan |
| [Receiver](#receiver) | volume, RF gain, squelch, preamp, attenuator, squelch status |
| [Meters](#meters) | S-meter |
| [Settings](#settings) | functions |

!!! note "Reading values from the radio"
    Blocks that read a value ask the radio and use its **last answer**. Right after the start there is no answer yet:
    numbers are then 0, yes/no questions are *false* and texts are empty. Use them in [Periodically](../base.md#periodically), where they are asked again and again.

!!! warning "CI-V address and baud rate"
    iCOMpadre talks to the radio with the CI-V address of the IC-705 (A4h) at 19200 baud. In the CI-V settings of the IC-78,
    set the **CI-V address to A4h** (the default is 62h) and the **CI-V baud rate to 19200** (or Auto).

!!! info "Not tested yet"
    The manual lists the CI-V commands of the IC-78 without their data. The blocks use the values of the other Icom radios (e.g. the 20 dB attenuator, the S-meter scale), they have not been tested with an IC-78 yet.

The CI-V commands and page numbers refer to the *IC-78 instruction manual, chapter 8*.
All blocks are created from the description of the radio in `studio/radio/ic78.js`.

## <span style="color:#5fa8c9">■</span> Frequency & Mode {#frequency}

### Set Frequency {#ic78_set_frequency}

![Set Frequency block](../img/ic78_set_frequency.png){ width="208" }

Sets the frequency of the radio.

CI-V: `05 + 5 bytes BCD, least significant byte first` (p. 41)

??? info "Lua code"
    ```lua
    sendCommand({0x05}, frequencyToBcd(14.074 * 1e6, 5))
    ```

### Set Operating Mode {#ic78_set_operating_mode}

![Set Operating Mode block](../img/ic78_set_operating_mode.png){ width="223" }

Sets the operating mode of the radio.
Choices: *LSB*, *USB*, *AM*, *CW*, *RTTY*, *CW-R*, *RTTY-R*.

CI-V: `06 + mode` (p. 41)

??? info "Lua code"
    ```lua
    sendCommand({0x06}, {0x00})
    ```

### Select Memory Channel {#ic78_select_memory}

![Select Memory Channel block](../img/ic78_select_memory.png){ width="208" }

Switches to the memory mode and selects the memory channel (1 ~ 99).

CI-V: `08 (memory mode), 08 + 0001 ~ 0099 (channel)` (p. 41)

??? info "Lua code"
    ```lua
    sendCommand({0x08})
    sendCommand({0x08}, numberToBcd(1, 2))
    ```

### Scan {#ic78_scan}

![Scan block](../img/ic78_scan.png){ width="109" }

Starts a scan of the selected type, or stops it.
Choices: *stop*, *memory*.

CI-V: `0E + 00 (stop) / scan type` (p. 41)

??? info "Lua code"
    ```lua
    sendCommand({0x0E, 0x00})
    ```

### Operating frequency {#ic78_get_operating_frequency}

![Operating frequency block](../img/ic78_get_operating_frequency.png){ width="219" }

Reads the current frequency of the radio.

CI-V: `03` (p. 41)

??? info "Lua code"
    ```lua
    icomReadFrequency()
    ```

### Operating Mode {#ic78_get_operating_mode}

![Operating Mode block](../img/ic78_get_operating_mode.png){ width="134" }

Reads the current operating mode of the radio (LSB, USB, AM, CW, RTTY, CW-R or RTTY-R).

CI-V: `04` (p. 41)

??? info "Lua code"
    ```lua
    icomName(icomQuery({0x04}), {[0] = "LSB", [1] = "USB", [2] = "AM", [3] = "CW", [4] = "RTTY", [7] = "CW-R", [8] = "RTTY-R"}, "Unknown")
    ```

### Attenuator {#ic78_get_attenuator}

![Attenuator block](../img/ic78_get_attenuator.png){ width="96" }

CI-V: `11 -> 00 / 20` (p. 41)

??? info "Lua code"

### Is Squelch open? {#ic78_is_squelch_open}

![Is Squelch open? block](../img/ic78_is_squelch_open.png){ width="142" }

*True* if the squelch is open, i.e. a signal is received.

CI-V: `15 01 -> 00 (closed) / 01 (open)` (p. 41)

??? info "Lua code"
    ```lua
    icomReadOn({0x15, 0x01})
    ```

## <span style="color:#5fa8c9">■</span> Meters {#meters}

### S-Meter {#ic78_get_s_meter}

![S-Meter block](../img/ic78_get_s_meter.png){ width="168" }

Reads the S-meter: in S-units (0 ~ 9), or in dB over S9 (negative below S9, 6 dB per S-unit).

CI-V: `15 02 -> 0000 = S0, 0120 = S9, 0241 = S9+60 dB` (p. 41)

??? info "Lua code"
    ```lua
    math.min(9, icomMeter({0x15, 0x02}, {{0, 0}, {120, 9}}))
    ```

## <span style="color:#5fa8c9">■</span> Settings {#settings}

### Switch function {#ic78_switch_function}

![Switch function block](../img/ic78_switch_function.png){ width="235" }

Switches a function of the radio on or off.
Choices: *Noise Blanker*, *Speech Compressor*.

CI-V: `16 xx + 00 (off) / 01 (on)` (p. 41)

??? info "Lua code"
    ```lua
    sendCommand({0x16, 0x22}, {0x01})
    ```

### Is function on? {#ic78_is_function_on}

![Is function on? block](../img/ic78_is_function_on.png){ width="193" }

*True* if the function of the radio is switched on.
Choices: *Noise Blanker*, *Speech Compressor*.

CI-V: `16 xx -> 00 (off) / 01 (on)` (p. 41)

??? info "Lua code"
    ```lua
    icomReadByte({0x16, 0x22}) ~= 0
    ```
